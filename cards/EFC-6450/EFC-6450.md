# EFC-6450 — Erro ao exportar dados NEE

> **Fonte:** Jira (`gruposalta.atlassian.net`) — somente leitura. Não edite campos sincronizados diretamente aqui.  
> **Status:** Aberta | **Tipo:** Sub-task | **Prioridade:** Medium | **Última sincronização:** 2026-06-11  
> **Parent:** EFC-6381 — Melhorias na Tipação de transtorno

---

## 1. Contexto e Motivação

Bug na tela de NEE após a implementação da EFC-6381. Ao clicar no botão "Exportar", ocorre um erro inesperado — os dados não são exportados.

**Ambiente:** Homologação

---

## 2. Critérios de Aceitação

- O botão "Exportar" deve gerar o arquivo (Excel/CSV) com os dados NEE sem erros.
- A exportação deve funcionar tanto para registros legados (`Diagnostico` texto livre) quanto para novos registros com `TipoTranstornoId`.

---

## 3. Subtarefas

Nenhuma subtarefa.

---

## 4. O Que Precisa Ser Feito

**Causa provável:** a query ou o serviço de exportação (`NeeGetRelatorioExportService` / `NecessidadesEspeciaisExport_Get.sql`) não foi atualizado para lidar com os novos campos adicionados na EFC-6381 (`TipoTranstornoId`, `TipoTranstornoOutro`, `PossuiLaudoStatus`). Pode ser um JOIN quebrado ou coluna inexistente na query de exportação.

**Investigação:**
1. Verificar o log de erro no backend ao acionar a exportação (Application Insights / logs locais).
2. Executar manualmente `NecessidadesEspeciaisExport_Get.sql` em homologação para identificar o erro.

**Backend:**
- Verificar `NecessidadesEspeciaisExport_Get.sql` — adicionar colunas `TipoTranstorno`, `TipoTranstornoOutro`, `PossuiLaudoStatus` com LEFT JOIN em `TipoTranstorno` (para não quebrar registros legados sem `TipoTranstornoId`).
- Verificar `NeeGetRelatorioExportService.cs` — confirmar que o mapeamento das novas colunas para o Excel está correto.

---

## 5. Arquivos Prováveis a Modificar

Repositório: `notas` — funcionalidade `NecessidadesEducacionaisEspeciais`.

- `NecessidadesEspeciaisExport_Get.sql` — adicionar LEFT JOIN em TipoTranstorno e novas colunas
- `NeeGetRelatorioExportService.cs` — mapeamento das novas colunas no Excel
