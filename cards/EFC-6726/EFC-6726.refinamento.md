# Refinamento — EFC-6726

> Gerado em: 2026-08-18

## Contexto

O frontend do `estrutura-pedagogica` está atualmente na versão 20.3 do Angular. O card pede a atualização para a versão 22, resolvendo breaking changes decorrentes tanto do próprio framework quanto de bibliotecas de terceiros. Duas dependências relevantes de UI (`ng-select` e `ng-bootstrap`) hoje declaram compatibilidade fechada apenas até Angular 20, exigindo upgrade de major version própria para acompanhar o Angular 22. Não há execução de testes automatizados no pipeline de CI atual (`buildspec.yml`) — a suíte de testes (unitários e E2E) é validada manualmente.

## User Story

**Como** time de desenvolvimento do `estrutura-pedagogica`,
**quero** atualizar o frontend Angular e suas dependências para a versão 22,
**para que** o projeto permaneça em uma versão suportada do framework, sem dívida técnica acumulada de dependências desatualizadas, e sem regressões nas telas existentes.

## Critérios de Aceite

- **CA-01:** A aplicação frontend compila e é executada utilizando Angular 22 (não mais a versão 20).
- **CA-02:** As bibliotecas de terceiros usadas nas telas (incluindo os campos de seleção e componentes de UI atualmente baseados em `ng-select` e `ng-bootstrap`) foram atualizadas para versões compatíveis com a nova versão do Angular.
- **CA-03:** Não há regressão visual ou funcional perceptível em nenhuma tela existente do sistema após a atualização.
- **CA-04:** Toda a suíte de testes automatizados existente (unitários e end-to-end) foi executada manualmente e está passando após a atualização.
- **CA-05:** O processo de build utilizado pelo pipeline de deploy continua funcionando normalmente após a atualização.
