Feature: Diário de Classe — estrutura-pedagogica

  Background:
    Given que o Diário de Classe está disponível em "estrutura-pedagogica"
    And a rede "Rede Alpha" possui configuração de caracteres:
      | Presença      | P |
      | Falta         | F |
      | Pendência     | - |
      | Transferência | T |
      | NEE           | N |
    And a configuração da rede habilita as seções: Frequência, Conteúdo Ministrado e Relatório de Rendimento

  # ─── ACESSO E FILTRO ──────────────────────────────────────────────────────

  Scenario: Professor acessa o Diário de Classe e aplica filtro completo
    Given que o usuário possui permissão "DiarioDeClasse" para a rede "Rede Alpha"
    When o usuário navega para "/diario-de-classe/listar"
    Then a tela é exibida com o FiltroComponent
    When o usuário seleciona:
      | Rede        | Rede Alpha   |
      | Escola      | Escola Teste |
      | Série       | 1º Ano EM    |
      | Turma       | 1A           |
      | Disciplina  | Matemática   |
      | Data início | 01/03/2026   |
      | Data fim    | 31/05/2026   |
    And clica em "Filtrar"
    Then o botão "Gerar Diário" aparece habilitado

  Scenario: Campos do filtro populam em cascata
    Given que o usuário possui permissão "DiarioDeClasse" para a rede "Rede Alpha"
    When o usuário acessa "/diario-de-classe/listar"
    And seleciona a rede "Rede Alpha"
    Then o campo "Escola" é habilitado e exibe apenas as escolas da rede
    When o usuário seleciona a escola "Escola Teste"
    Then o campo "Série" é habilitado
    When o usuário seleciona a série "1º Ano EM"
    Then o campo "Turma" é habilitado
    When o usuário seleciona a turma "1A"
    Then o campo "Disciplina" é habilitado e exibe as disciplinas da turma

  Scenario: Usuário sem permissão não acessa o Diário de Classe
    Given que o usuário NÃO possui permissão "DiarioDeClasse"
    When o usuário tenta navegar para "/diario-de-classe/listar"
    Then é redirecionado para a tela de acesso negado

  # ─── GERAÇÃO DO DOCUMENTO ─────────────────────────────────────────────────

  Scenario: Documento é gerado com todas as seções habilitadas
    Given que o usuário aplicou filtro válido para a turma "1A — Matemática"
    And a configuração da rede habilita Frequência, Conteúdo Ministrado e Relatório de Rendimento
    When o usuário clica em "Gerar Diário"
    Then o overlay de documento é aberto
    And o documento exibe o cabeçalho com nome da escola, cidade e turma
    And o documento exibe a grade de chamada (datas × alunos) com os caracteres da rede
    And o documento exibe a tabela de conteúdo ministrado
    And o documento exibe o relatório de rendimento por etapa

  Scenario: Documento omite seção desabilitada na configuração da rede
    Given que a configuração da rede "Rede Alpha" tem "ExibirConteudoMinistrado = false"
    And o usuário aplicou filtro válido
    When o usuário clica em "Gerar Diário"
    Then o overlay de documento é aberto
    And o documento NÃO exibe a tabela de conteúdo ministrado
    And o documento exibe normalmente a grade de chamada e o relatório de rendimento

  Scenario: Grade de chamada exibe os caracteres corretos por aluno
    Given que o documento foi gerado para a turma "1A — Matemática" no período 01/03 a 31/03
    Then na grade de chamada, alunos presentes aparecem com o caractere "P"
    And alunos com falta aparecem com o caractere "F"
    And campos de frequência não lançada aparecem com o caractere "-"

  Scenario: Documento pode ser exportado como PDF
    Given que o overlay de documento está aberto com o diário gerado
    When o usuário clica em "Exportar PDF"
    Then o arquivo PDF é baixado com nome no formato "diario-NOMEREDE-NOMETURMA-dd_mm_yyyy"

  Scenario: Documento pode ser impresso
    Given que o overlay de documento está aberto com o diário gerado
    When o usuário clica em "Imprimir"
    Then o diálogo de impressão do navegador é aberto

  # ─── PAINEL "CONFIGURAR DOCUMENTO" (overlay) ──────────────────────────────

  Scenario: Usuário alterna seções do documento pelo painel lateral
    Given que o overlay de documento está aberto
    When o usuário clica em "Configurar Documento"
    Then o painel lateral abre com os toggles:
      | Frequência              |
      | Conteúdo ministrado     |
      | Relatório de rendimento |
      | Nome do(a) professor(a) |
    When o usuário desabilita o toggle "Conteúdo ministrado"
    Then a grade de conteúdo desaparece do documento imediatamente
    And essa alteração NÃO é salva no banco — vale apenas para o documento atual

  # ─── TELA DE CONFIGURAÇÃO DE CARACTERES ───────────────────────────────────

  Scenario: Coordenador acessa a tela de configuração via aba
    Given que o usuário possui permissão "DiarioDeClasse_Configuracao"
    When o usuário acessa "/diario-de-classe/listar"
    Then a aba "Configuração" aparece ao lado da aba "Diário de Classe"
    When o usuário clica na aba "Configuração"
    Then é navegado para "/diario-de-classe/configurar"

  Scenario: Usuário sem permissão de configuração não vê a aba Configuração
    Given que o usuário possui apenas a permissão "DiarioDeClasse" (sem "DiarioDeClasse_Configuracao")
    When o usuário acessa "/diario-de-classe/listar"
    Then a aba "Configuração" NÃO é exibida

  Scenario: Tela de configuração fica desabilitada até o usuário selecionar uma rede
    Given que o usuário está em "/diario-de-classe/configurar"
    Then o bloco de campos de caracteres está desabilitado
    And exibe a mensagem "Selecione uma rede para editar a configuração de caracteres"

  Scenario: Configuração existente é carregada ao selecionar uma rede
    Given que o usuário está em "/diario-de-classe/configurar"
    And a rede "Rede Alpha" já possui configuração salva (P, F, -, T, N)
    When o usuário seleciona "Rede Alpha" no dropdown
    Then os campos de caracteres são preenchidos com os valores salvos (P, F, -, T, N)

  Scenario: Rede sem configuração exibe valores padrão com aviso
    Given que o usuário está em "/diario-de-classe/configurar"
    And a rede "Rede Beta" ainda NÃO possui configuração cadastrada
    When o usuário seleciona "Rede Beta"
    Then os campos exibem os valores padrão (P, F, -, T, N)
    And um aviso amarelo informa "Esta rede ainda não possui configuração. Os valores exibidos são os padrões — salve para criar a configuração."

  Scenario: Preview atualiza em tempo real ao editar um caractere
    Given que o usuário selecionou "Rede Alpha" e os campos estão preenchidos
    When o usuário altera o campo "Presença" de "P" para "X"
    Then a tabela de preview atualiza imediatamente
    And todas as células de presença passam a exibir "X"

  Scenario: Highlight conecta campo editado com coluna na tabela de preview
    Given que o usuário está editando a configuração da "Rede Alpha"
    When o usuário foca no campo "Falta"
    Then a linha correspondente ao tipo "Falta" no painel de configuração é realçada
    And as células da coluna "Falta" na tabela de preview são destacadas visualmente

  Scenario: Coordenador salva configuração de caracteres
    Given que o usuário está em "/diario-de-classe/configurar" com "Rede Alpha" selecionada
    When o usuário altera "Presença" para "X" e "Falta" para "A"
    And clica em "Salvar configuração"
    Then a configuração é salva via POST para "api/diariodeclasse/configuracao/save"
    And o botão exibe "Salvo!" por 2,5 segundos e volta ao estado original

  Scenario: Erro ao salvar exibe banner de erro
    Given que o usuário clicou em "Salvar configuração"
    And a requisição retorna erro 500
    Then um banner vermelho é exibido abaixo do botão com a mensagem de erro
    And o botão volta ao estado normal

  Scenario: Campo de caractere não aceita mais de um caractere
    Given que o usuário está editando um campo de caractere
    When o usuário digita dois caracteres seguidos, como "AB"
    Then apenas o primeiro caractere é aceito no campo

  # ─── INTEGRIDADE DOS DADOS ────────────────────────────────────────────────

  Scenario: Dados do documento são equivalentes ao diário atual para o mesmo filtro
    Given que o mesmo filtro é aplicado no diário atual ("documentacao-pedagogica") e no novo ("estrutura-pedagogica")
    Then a lista de alunos é a mesma em ambos
    And os caracteres de chamada de cada aluno por data coincidem
    And os conteúdos ministrados por data coincidem
    And as notas por aluno/etapa no relatório de rendimento coincidem
