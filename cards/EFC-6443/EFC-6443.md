# EFC-6443 — ⚠️Migração do diário de classe para estrutura pedagógica

> **Fonte:** Jira (`gruposalta.atlassian.net`) — somente leitura. Não edite campos sincronizados diretamente aqui.  
> **Status:** Backlog | **Tipo:** Story | **Prioridade:** Medium | **Última sincronização:** 2026-06-09 17:40

---

## 1. Contexto e Motivação

tualmente o diário de classe é um frontend próprio no repositório `documentacao-pedagogica` que chama os backends de `frequencia` e `barramento-pedagogico` para buscar informações de frequência, conteúdo e rendimento, conforme configuração. Fora o filtro, o frontend não usa nada que seja específico de `documentacao-pedagogica`.

om a migração do módulo de frequência para `estrutura-pedagogica`, será necessário criar um novo endpoint para os dados do diário. A oportunidade é usada para migrar todo o documento para `estrutura-pedagogica`, simplificando sua estrutura ao mesmo tempo.

---

## 2. Critérios de Aceitação

Itens a fatiar (cada um é uma entrega incremental):

1. Filtro
2. Construção do documento
3. Exibição da frequência no documento (mediante configuração)
4. Exibição de conteúdo no documento (mediante configuração)
5. Exibição do relatório de rendimento no documento (mediante configuração)
6. Permitir configurar o que aparece ou não no documento "ao vivo", em vez de por aba dedicada

---

## 3. Subtarefas

Nenhuma subtarefa cadastrada no Jira.

---

## 4. O Que Precisa Ser Feito

- Criar novo endpoint em `estrutura-pedagogica` (backend) que sirva os dados do diário (frequência, conteúdo, rendimento).
- Migrar o componente de diário de classe do repo `documentacao-pedagogica` para `estrutura-pedagogica` (frontend).
- Remover (ou desativar) a dependência direta do frontend de diário em `documentacao-pedagogica` para os backends `frequencia` e `barramento-pedagogico`.
- Implementar a lógica de configuração de exibição de seções "ao vivo" (frequência, conteúdo, rendimento) sem necessitar de aba dedicada.

---

## 5. Arquivos Prováveis a Modificar

**Backend (`estrutura-pedagogica`):**
- Novo controller/endpoint para dados do diário de classe

**Frontend (`estrutura-pedagogica`):**
- Novo módulo/componente de diário de classe (migrado de `documentacao-pedagogica`)
- Configuração de roteamento para incluir o diário

**Frontend (`documentacao-pedagogica`):**
- Remoção ou deprecação do componente de diário atual

> Consultar `frontend-maps/estrutura-pedagogica-angular-map.md` e `frontend-maps/documentacao-pedagogica-angular-map.md` para localizar os componentes exatos antes de começar.
