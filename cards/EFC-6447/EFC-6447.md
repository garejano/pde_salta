# EFC-6447 — Subitens aparecem na listagem de transtornos e não são carregados no segundo select

> **Fonte:** Jira (`gruposalta.atlassian.net`) — somente leitura. Não edite campos sincronizados diretamente aqui.  
> **Status:** Em Desenvolvimento | **Tipo:** Sub-task | **Prioridade:** Medium | **Última sincronização:** 2026-06-11  
> **Parent:** EFC-6381 — Melhorias na Tipação de transtorno

---

## 1. Contexto e Motivação

Bug no formulário NEE após a implementação da EFC-6381. A seleção dos transtornos TEA e TEAp não habilita um segundo select com os subitens. Além disso, os subitens que deveriam aparecer apenas no segundo select estão sendo listados no primeiro select junto com os itens raiz.

**Ambiente:** Homologação

---

## 2. Critérios de Aceitação

- Subitens (ex: TEA Nível 1/2/3, Dislexia etc.) **não** devem aparecer no primeiro select — apenas os itens raiz.
- Ao selecionar TEA ou TEAp no primeiro select, um segundo select deve ser exibido com os subitens correspondentes.
- A seleção do subitem é obrigatória — o pai não pode ser salvo diretamente.

---

## 3. Subtarefas

Nenhuma subtarefa.

---

## 4. O Que Precisa Ser Feito

**Causa provável:** o endpoint `GET /tipo-transtorno` está retornando todos os itens (raiz + subitens) em vez de retornar apenas os itens raiz com os subitens aninhados. O frontend está exibindo a lista plana.

**Backend:**
- Verificar `TipoTranstornoRepository` — a query deve filtrar `WHERE ParentId IS NULL` e fazer eager load dos subitens.
- Garantir que o endpoint retorna apenas raízes com `Subitens` preenchidos.

**Frontend (`edicao-nee.component.ts`):**
- Verificar a condição que detecta se o item selecionado tem subitens (`item.subitens?.length > 0`).
- O segundo select deve ser exibido e populado com `item.subitens` quando a condição for verdadeira.
- Garantir que o `FormControl` do segundo select é resetado ao trocar o primeiro.

---

## 5. Arquivos Prováveis a Modificar

Repositório: `notas` — funcionalidade `NecessidadesEducacionaisEspeciais`.

- `TipoTranstornoRepository.cs` — filtrar apenas raízes no GET
- `edicao-nee.component.ts` — lógica do segundo select condicional
- `edicao-nee.component.html` — exibição condicional do segundo select
