# EFC-6508 — Dias letivos extras - ajuste de exclusão, inclusão e edição

> **Fonte:** Jira (`gruposalta.atlassian.net`) — somente leitura. Não edite campos sincronizados diretamente aqui.  
> **Status:** Em Desenvolvimento | **Tipo:** Story | **Prioridade:** Medium | **Última sincronização:** 2026-06-23 17:57

---

## 1. Contexto e Motivação

Formulário de inclusão/edição de dias letivos extras era um modal pequeno demais para a quantidade de informação (duas colunas: campos + filtro turno/série à esquerda; lista de turmas/frentes à direita). A solução é substituir o modal por uma página dedicada com mais espaço.

---

## 2. Critérios de Aceitação

- Botão "Novo dia letivo extra" navega para `/dia-letivo-extra/novo` em vez de abrir modal
- Botão "Ver/Editar" navega para `/dia-letivo-extra/editar/:hash`
- Página de inclusão/edição exibe `app-titulo-page` + `app-tab-periodo-letivo` (igual à listagem)
- Botão "← Voltar para a listagem" acima do formulário retorna para `/dia-letivo-extra/listar`
- Todas as funcionalidades do formulário anterior são mantidas: seleção de turmas/frentes, filtro por turno/série, validação, save, exclusão com confirmação
- Acesso direto à URL (sem contexto de filtro) redireciona para a listagem

---

## 3. Subtarefas

Nenhuma subtarefa.

---

## 4. O Que Foi Feito

### Componente de página (`formulario-page/`)

**Novo:** `formulario-page/formulario-page.component.ts/html/scss`

Substitui `formulario/formulario.component` (modal). Mesmo componente para criar e editar — modo determinado pelo parâmetro `:hash` na rota.

Contexto de filtro (escolas, anoLetivo, item em edição) passado via `FiltroDiaLetivoExtraService.contextoFormulario`. Se `null` ao montar, redireciona para a listagem.

Após save ou exclusão bem-sucedidos, navega de volta para `/dia-letivo-extra/listar`.

### Rotas (`dia-letivo-extra.routes.ts`)

Adicionadas:
- `novo` → `FormularioDiaLetivoExtraPageComponent`
- `editar/:hash` → `FormularioDiaLetivoExtraPageComponent`

### Listagem (`listar/listar.component.ts/html`)

- `abrirFormulario()`: seta `contextoFormulario` no service e navega para `novo`
- `editarItem(item)`: seta `contextoFormulario` com o item e navega para `editar/:hash`
- Removidos: `@ViewChild("formulario")`, `onUpdateList()`, `inativar()`, import de `FormularioDiaLetivoExtraComponent`
- Template: removida tag `<app-formulario-dia-letivo-extra>`

### `FiltroDiaLetivoExtraService`

Adicionado: `contextoFormulario: FormularioContext | null` — estado transitório que a listagem preenche antes de navegar e a página de formulário consome e limpa no `ngOnInit`.

### `CheckComponent` (`src/shared/components/check/`)

Bug corrigido: adicionado input `tooltip` (renderizado via `[title]` no `<label>`). Usado nas frentes bloqueadas para exibir "Essa disciplina já possui uma aula cadastrada neste dia."
