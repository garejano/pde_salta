## 4. O Que Precisa Ser Feito

Cadastrar o RA de 1 aluno seguindo o processo manual já documentado em `projetos/importador_impulso/manual/guide.md`:

1. Resolver escola/turma no banco (`manual/scripts/resolve_ids_ra_impulso.sql`) — "Colégio Estadual Jardim Panorama" / "2A" (2ª série EM) pode já estar mapeado, já que a mesma escola (Jardim Panorama) apareceu no ciclo EFC-7017 (out/26). Conferir se a turma "2A" bate com algum mapeamento existente antes de descobrir do zero.
2. Rodar Query 2 (próximo RA disponível) — **sempre reconsultar em cada ambiente**, nunca reaproveitar `--ra-start` de outro ciclo (ver `manual/guide.md`, seção "Regras importantes" — incidente já ocorrido no EFC-6732).
3. Gerar o SQL de INSERT via `gerar_ra_impulso.py` com uma lista de 1 aluno só (CSV `escola,nome,turma` com 1 linha, usando `--alunos-csv`).
4. Executar o SQL no banco (produção é sempre manual — IA não tem acesso via MCP).
5. Conferir com a query de confirmação do Passo 6 do guide.

Nota: card é um "CLONE", possivelmente derivado de um card anterior (ex.: EFC-7017, que envolveu a mesma escola Jardim Panorama) — vale checar se o pedido é continuação/correção pontual daquele ciclo (ex.: a aluna Sophia Olinda A. Nogueira ficou pendente no EFC-7017 por suspeita de RA duplicado — **nome diferente** da aluna deste card, Sophia Boldin da Silva, não confundir as duas).
