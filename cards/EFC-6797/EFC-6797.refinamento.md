# Refinamento — EFC-6797

> Gerado em: 2026-09-10

## Contexto

No Painel do Aluno, os dados de comportamento (positivo/negativo) são exibidos hoje na listagem de alunos, na ficha do aluno e na tela de detalhes de comportamento. Atualmente esse acesso é controlado apenas por permissão do usuário, sem considerar se a turma do aluno de fato utiliza registro de comportamento. Isso faz com que turmas sem essa configuração exibam indicadores de comportamento vazios ou irrelevantes. O sistema já resolve um problema equivalente para os registros de ocorrência, através de uma configuração de turma que indica se ela usa pontuação ou quantidade — o mesmo padrão deve ser aplicado aqui.

## User Story

**Como** usuário do Painel do Aluno,
**quero** visualizar informações de comportamento apenas para alunos cuja turma esteja configurada para utilizar registro de comportamento,
**para que** eu não veja indicadores irrelevantes ou vazios para turmas que não usam esse recurso.

## Critérios de Aceite

- **CA-01:** Na listagem do Painel do Aluno, os indicadores de comportamento (positivo/negativo) só devem aparecer para alunos de turmas com a configuração de registro de comportamento ativa.
- **CA-02:** Na ficha do aluno, os indicadores/KPIs de comportamento só devem ser exibidos quando a turma do aluno possuir essa configuração ativa.
- **CA-03:** A opção de acessar os detalhes de comportamento do aluno só deve estar disponível quando a turma possuir a configuração ativa.
- **CA-04:** Para turmas sem a configuração ativa, nenhuma referência a comportamento (positivo, negativo ou comentários) deve aparecer em nenhuma das três telas acima.
- **CA-05:** O comportamento de exibição por permissão do usuário já existente deve continuar funcionando normalmente, combinado com essa nova regra por turma (ambas as condições precisam ser satisfeitas).

## Regras de Negócio

| # | Condição | Comportamento |
|---|----------|---------------|
| RN-01 | Turma do aluno **não** possui configuração de registro de comportamento ativa | Ocultar todos os indicadores e opções de comportamento nas três telas do Painel do Aluno |
| RN-02 | Turma do aluno possui configuração de registro de comportamento ativa **e** usuário tem permissão para visualizar comportamento | Exibir normalmente os indicadores e opções de comportamento |
| RN-03 | Turma do aluno possui configuração ativa **mas** usuário não tem permissão para visualizar comportamento | Manter ocultação por permissão (regra já existente, sem alteração) |

## Testes E2E (Gherkin)

```gherkin
Feature: Exibição condicional de dados de comportamento no Painel do Aluno

  Background:
    Given estou autenticado no Painel do Aluno com permissão para visualizar comportamento

  Scenario: Turma sem configuração de registro de comportamento não exibe indicadores na listagem
    Given existe um aluno matriculado em uma turma sem configuração de registro de comportamento
    When acesso a listagem do Painel do Aluno
    Then não devo ver nenhum indicador de comportamento para esse aluno

  Scenario: Turma com configuração de registro de comportamento exibe indicadores na listagem
    Given existe um aluno matriculado em uma turma com configuração de registro de comportamento ativa
    When acesso a listagem do Painel do Aluno
    Then devo ver os indicadores de comportamento (positivo/negativo) desse aluno

  Scenario: Ficha do aluno oculta indicadores de comportamento quando a turma não possui a configuração
    Given existe um aluno matriculado em uma turma sem configuração de registro de comportamento
    When acesso a ficha desse aluno
    Then não devo ver indicadores de comportamento na ficha

  Scenario: Opção de detalhes de comportamento não está disponível para turma sem a configuração
    Given existe um aluno matriculado em uma turma sem configuração de registro de comportamento
    When acesso a ficha desse aluno
    Then não devo ver a opção de acessar os detalhes de comportamento

  Scenario: Opção de detalhes de comportamento está disponível para turma com a configuração
    Given existe um aluno matriculado em uma turma com configuração de registro de comportamento ativa
    When acesso a ficha desse aluno e seleciono a opção de detalhes de comportamento
    Then devo visualizar a tela de detalhes de comportamento do aluno
```
