# Refinamento — EFC-6665

> Gerado em: 2026-07-31

## Contexto

Hoje, `documentacao-pedagogica` sincroniza o percentual de frequência do aluno consultando o módulo legado de frequência, que já não é o sistema responsável pelo lançamento de frequência — essa responsabilidade migrou para `estrutura-pedagogica`. O percentual de frequência do aluno já é calculado e mantido lá (na base usada também pelo Painel do Aluno). É necessário que `estrutura-pedagogica` passe a fornecer esse dado diretamente, para que a sincronização continue funcionando sem depender do módulo antigo.

## User Story

**Como** serviço de sincronização de frequência do `documentacao-pedagogica`,
**quero** consultar o percentual de frequência do aluno diretamente em `estrutura-pedagogica`,
**para que** o histórico escolar do aluno continue sendo atualizado corretamente, sem depender do módulo legado de frequência que está sendo descontinuado.

## Critérios de Aceite

- **CA-01:** Ao consultar o percentual de frequência de um aluno, o sistema deve retornar um percentual para cada combinação de ano letivo e série em que o aluno teve frequência calculada.
- **CA-02:** A consulta deve identificar o aluno pelo mesmo identificador de origem (hash) já utilizado hoje na integração entre os dois sistemas.
- **CA-03:** Cada percentual retornado deve indicar de forma inequívoca a qual ano letivo e série de origem ele se refere.
- **CA-04:** O percentual retornado deve refletir o valor mais atualizado calculado em `estrutura-pedagogica`.
- **CA-05:** A forma como `documentacao-pedagogica` processa a resposta não deve precisar mudar — apenas a origem da consulta muda, do módulo legado para `estrutura-pedagogica`.
- **CA-06:** Se o aluno não possuir nenhum percentual de frequência calculado (ex.: aluno sem lançamentos suficientes), a consulta deve retornar uma lista vazia, sem indicar erro.
- **CA-07:** Um identificador de aluno inexistente ou inválido não deve interromper a sincronização — o sistema deve responder de forma tratada, sem quebrar o processo.

## Regras de Negócio

| # | Condição | Comportamento |
|---|----------|---------------|
| RN-01 | O identificador de origem informado não corresponde a nenhum aluno conhecido | Retorna lista vazia, sem erro |
| RN-02 | Aluno possui percentual calculado apenas para parte dos anos letivos/séries em que esteve matriculado | Retorna somente os anos letivos/séries com percentual calculado |
| RN-03 | Aluno possui matrículas em séries diferentes dentro do mesmo ano letivo | Retorna um percentual distinto para cada série |

## Testes E2E (Gherkin)

```gherkin
Feature: Consulta de percentual de frequência do aluno para sincronização com documentacao-pedagogica

  Background:
    Given um aluno cadastrado em estrutura-pedagogica com identificador de origem conhecido

  Scenario: Consultar percentual de frequência de aluno com histórico em múltiplos anos letivos
    Given o aluno possui percentual de frequência calculado para o ano letivo 2025 na 6ª série
    And o aluno possui percentual de frequência calculado para o ano letivo 2026 na 7ª série
    When a sincronização de documentacao-pedagogica consulta o percentual de frequência desse aluno pelo identificador de origem
    Then o sistema retorna um percentual referente ao ano letivo 2025 na 6ª série
    And o sistema retorna um percentual referente ao ano letivo 2026 na 7ª série

  Scenario: Consultar percentual de frequência de aluno sem dado calculado
    Given o aluno não possui nenhum percentual de frequência calculado em estrutura-pedagogica
    When a sincronização de documentacao-pedagogica consulta o percentual de frequência desse aluno
    Then o sistema retorna uma lista vazia
    And nenhum erro é reportado à sincronização

  Scenario: Consultar percentual de frequência com identificador de origem inexistente
    Given o identificador de origem informado não corresponde a nenhum aluno conhecido em estrutura-pedagogica
    When a sincronização de documentacao-pedagogica consulta o percentual de frequência
    Then o sistema retorna uma lista vazia
    And a sincronização não é interrompida por erro
```
