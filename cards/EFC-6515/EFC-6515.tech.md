# Plano Técnico — EFC-6515

> Gerado em: 2026-06-25

## Contexto

O refinamento define uma nova tela de **Matriz Curricular** que complementa o Configurador de Disciplinas já existente. Todos os campos necessários (`NomeDocumentosOficiais`, `AreaConhecimentoId`, `OcultarNaMatrizCurricular`, `ParteDaMatrizCurricular`, `EhEnriquecimentoCurricular`) já existem em `RedeSerieDisciplina`; `CargaHoraria` também já existe com seus campos. Não há colunas novas no banco. A implementação segue exatamente o mesmo padrão Disable+Insert do Configurador de Disciplinas, com três diferenças-chave: filtro por **Segmento** (em vez de Agrupamento), campos editáveis diretamente pelo usuário (em vez de via Configurador), e a nova funcionalidade `MatrizCurricular = 49`.

---

## Convenções aplicáveis

1. Schema por scripts SQL manuais — nenhuma EF Migration. Toda tabela nova ou valor novo no banco requer script `.sql` em `cards/EFC-6515/sql/`.
2. Padrão Disable+Insert para `RedeSerieDisciplina` e `CargaHoraria` — reutilizar exatamente o pattern de `ConfiguradorDisciplinas/SaveService.cs`.
3. DTOs de entrada usam `Hash (Guid)`, nunca `Id` numérico; parâmetros de filtro vão no corpo, nunca em querystring.
4. Endpoints que alteram dados declaram e usam `unitOfWork`. Controllers sem lógica de negócio.
5. Registro automático por reflection — não declarar serviços/repositórios no DI manualmente.
6. C# 12 primary constructors, sem FluentValidation, `Count == 0` / `Count > 0`, sem `.Result`/`.Wait()`, chaves `{}` sempre.
7. HTML Angular: usar shared/dynamic components obrigatoriamente (`<app-button>`, `<text-field>`, `<app-number-field>` etc.). Componentes standalone sempre.
8. O Configurador de Disciplinas já preserva campos de Matriz ao fazer Disable+Insert e bloqueia remoção de disciplinas com `ParteDaMatrizCurricular = true`. Essa interdependência **não deve ser alterada**.

---

## Critérios de Aceite

- CA-01: Filtro por Ano Letivo (mín. 2015, mais recente pré-selecionado), Rede e Segmento (apenas com documentação pedagógica).
- CA-02: Listagem com nome interno, nome na Matriz, área do conhecimento, séries (tags), enriquecimento curricular, carga horária, botão editar.
- CA-03: Disciplinas inativas ou marcadas para ocultar não aparecem.
- CA-04: Nome variável por série → exibe o primeiro com indicação de "outros".
- CA-05: Busca e paginação client-side.
- CA-06: Dados auxiliares carregados uma vez no filtro, reutilizados no painel.
- CA-07: Side-panel unificado inclusão/edição (dois componentes separados com estrutura compartilhada).
- CA-08: Dropdown de disciplinas mãe não arquivadas; visíveis excluídas; removidas/ocultas incluídas para reinserção.
- CA-09: Seleção de disciplina pré-seleciona todas as séries com nome padrão.
- CA-10: Área do conhecimento (opcional), enriquecimento (toggle, off por padrão), nome e carga por série.
- CA-11: Pelo menos uma série obrigatória.
- CA-12: Atalho "aplicar a todas" para nome e carga.
- CA-13: Aviso sobre disciplinas sem avaliações no painel de inclusão.
- CA-14: Disciplinas incluídas: `PossuiAvaliacoesRegulares = false`, `PossuiAvaliacoesDiversificadas = false`.
- CA-15: Edição: disciplina não trocável; demais campos editáveis.
- CA-16: Salvar habilitado apenas com alteração.
- CA-17: Unicidade de `NomeDocumentosOficiais` por série (validação backend).
- CA-18: Remoção da Matriz não afeta o Configurador.
- CA-19: Reinserção de disciplinas removidas pelo painel de inclusão.
- CA-20: Carga horária em 3 formatos; exibida no formato digitado.
- CA-21: Armazenada em minutos + formato original.
- CA-22: Total da série recalculado automaticamente em hh:MM.
- CA-23: Exportação linha por Série × Disciplina.

## Restrições e riscos

- **Nenhuma coluna nova no banco** — todos os campos já existem. O único script SQL necessário é para a `Funcionalidade` e `MenuItem`.
- **Verificar Id=49** — confirmar no banco de produção que o Id 49 não está em uso por outra funcionalidade antes de executar o script.
- **`NomeDocumentosOficiaisRepetido`** — o método `GetNomeRepetido` existente verifica `NomeExibicao`; é necessário novo método ou parâmetro adicional para verificar `NomeDocumentosOficiais`.
- **`CargaHorariaParser`** — lógica nova no projeto; merece testes unitários próprios além dos de integração.
- **Interdependência com Configurador de Disciplinas** — `ConfiguradorDisciplinas/SaveService.cs` já preserva campos de Matriz no Disable+Insert e `DisableService.cs` já bloqueia remoção de `ParteDaMatrizCurricular = true`. Não modificar esses comportamentos.
- **Side-panel unificado (CA-07)** — implementado como dois componentes separados (`incluir/` e `editar/`) para manter consistência com o padrão do Configurador; lógica compartilhada pode ser extraída para um serviço Angular ou componente de formulário base se necessário.
- **Reinserção (CA-19)** — `GetDisciplinasDisponiveisParaMatriz` precisa incluir registros com `ParteDaMatrizCurricular = false` para permitir reinserção; lógica difere de `GetDisponiveis` do Configurador.
