## 1. Contexto e Motivação

**ARQUIVO MD EM ANEXO** (anexo não recuperado via API — verificar diretamente no Jira).

Professores de diversas unidades relataram dificuldades no Diário de Classe: após realizar o registro de conteúdo, o mesmo desaparece ao consultar novamente os dias já preenchidos. O lançamento é salvo, mas ao retornar à consulta o campo "Conteúdo" não aparece mais.

O erro ocorre com professores de disciplinas variadas. Caso relatado como exemplo:
- Unidade: Butantã
- Disciplina: Matemática, 8º ano
- Período: dias 26/06 até a data de abertura do card

Label: `OTRS` (chamado de suporte).

## 4. O Que Precisa Ser Feito

Investigar por que o campo "Conteúdo" do Diário de Classe é perdido após o salvamento, apesar do lançamento ser confirmado como salvo no momento do registro. Possíveis frentes de investigação:

- Verificar se há sobrescrita do registro por outro lançamento (ex.: nova gravação sem o campo, substituindo o conteúdo salvo).
- Verificar se é um problema de cache (client-side ou API) que mascara o valor persistido ao consultar novamente.
- Verificar histórico/log de alterações do registro de diário para os dias e turma relatados (Butantã, Matemática, 8º ano, a partir de 26/06) para confirmar se o dado foi de fato removido no banco ou apenas não é exibido corretamente na consulta.
- Confirmar se o problema é isolado a essa unidade/disciplina ou generalizado (o relato menciona "disciplinas variadas").
